# V0.7.0 成长实验验收清单

## 功能范围

- 新增个人成长实验区，支持创建、查看、编辑、复盘和删除。
- 每条实验记录包含名称、假设、行动、开始日期、计划结束日期、状态、观察结果和复盘。
- 名称、假设、行动为必填；结束日期不得早于开始日期。
- 状态分为准备开始、进行中、已复盘。
- 数据保存在独立 localStorage 键 `xinge-growth-experiments-v1`，不覆盖情绪日记、价值观罗盘或旧版反思练习。
- 支持 JSON 导出、逐条删除确认、清空全部记录确认、存储错误反馈。
- 不生成成长分数、人格类型或心理诊断。

## 手工验收步骤

1. 打开网站并进入「成长实验」。空状态应显示创建入口。
2. 尝试只填名称后保存，应提示填写假设与具体行动。
3. 输入结束日期早于开始日期，应提示日期错误。
4. 创建一条实验并保存；卡片应显示名称、状态、日期、假设和行动。
5. 刷新页面，确认记录恢复。
6. 编辑实验并补充观察结果与复盘，保存后卡片应更新。
7. 将状态改为「已复盘」，确认状态文案更新。
8. 导出 JSON，确认文件包含 `format: xinge-growth-experiments` 和 `experiments` 数组。
9. 删除一条记录，取消确认时记录保留，确认后记录移除。
10. 清空记录需要再次确认；取消时不得清空。
11. 检查移动端布局、键盘焦点、表单错误提示和空状态。
12. 检查其他模块数据不受影响。
