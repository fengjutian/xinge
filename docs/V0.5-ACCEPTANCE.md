## 本地验证步骤

1. 执行 `npm install`。
2. 执行 `npm run check:deploy`。
3. 执行 `npm run build`。
4. 执行 `npm run dev`，打开首页并进入“情绪日记”。
5. 不填内容点击保存，确认出现字段提示。
6. 填写至少一项情境/身体感受/需要，选择情绪和标签后保存。
7. 刷新页面，确认记录仍在。
8. 用关键词搜索并用情绪和标签筛选。
9. 点击标签频次线索，确认筛选结果变化。
10. 导出 JSON，确认文件包含 `format: xinge-emotion-journal`、版本号和记录数组。
11. 删除一条记录，分别测试取消与确认。
12. 确认旧版“心理机制实验室”的记录未被覆盖。
13. 缩窄浏览器视口，检查表单、图表和历史记录布局。
