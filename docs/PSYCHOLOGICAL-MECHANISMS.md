# 心格心理机制内容与开发规范

## 目标

将心理学理论转化为可观察、可练习的日常工具。机制用于提出问题，不用于诊断、预测人格或替代专业支持。

## 内容原则

1. 先描述情境与过程，再提供概念名称。
2. 同时呈现机制的短期功能、长期代价和适用边界。
3. 不把想法简单分成“正确／错误”，不要求用户强迫积极思考。
4. 每项机制至少提供一条原始或权威机构来源。
5. 互动记录默认仅保存在浏览器，并明确告知用户。

## 第一批交付

心理机制页面新增机制浏览器，包含：

- 情绪调节过程：识别情境选择、情境调整、注意部署、认知改变与反应调节。
- 反刍循环：区分是否产生新信息、行动或结束点。
- 体验回避：观察为了摆脱内在体验而采取的行为及其代价。
- 回避与负强化：解释回避为何会因短期焦虑下降而被重复。
- 基本心理需要：观察自主、胜任与联结，不作为需要测验或人格分类。

## 后续验收

- 所有机制在手机与桌面端均可访问。
- 键盘可切换机制选项，当前选项具有可感知状态。
- 每项包含来源、适用边界和非诊断声明。
- 内容不得承诺疗效，不得将单次反应等同于心理障碍。
