# V0.6.0 价值观罗盘验收清单

## 功能范围

- [x] 展示 16 项价值方向及简短解释。
- [x] 最多选择 5 项；未达 3 项时提示补充后再保存。
- [x] 使用上移/下移按钮调整优先顺序，按钮边界状态正确。
- [x] 记录价值选择原因、近期实践和未来一周的小行动。
- [x] 独立 localStorage 键 `xinge-value-compass-v1`，不覆盖情绪日记和旧反思记录。
- [x] 支持 JSON 导出和确认后清除。
- [x] 存储失败提示；没有人格标签、心理诊断或“价值观分数”。
- [x] 移动端响应式布局与键盘焦点样式。

## 浏览器手工验收

1. 运行 `npm install` 与 `npm run dev`，打开本地站点。
2. 在价值观罗盘选择 1–2 项并保存，确认出现至少选择 3 项的提示。
3. 选择 3–5 项，调整排序，填写三个反思问题并保存。
4. 刷新页面，确认选择、顺序与文字恢复。
5. 导出 JSON，确认下载文件含 `format: xinge-value-compass` 和 `reflection`。
6. 检查情绪日记、价值观练习和旧反思分别保存；清除其中一项不应影响另外两项。
7. 点击重置并取消，数据应保留；再次确认，价值观练习应清空。
8. 在窄屏宽度下检查卡片、按钮、文本输入与导航无横向溢出。
9. 检查浏览器 Console，无运行时错误。
