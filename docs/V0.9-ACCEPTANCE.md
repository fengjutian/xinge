# V0.9.0 验收说明：心理学知识依赖网络

日期：2026-10-30

## 本版目标

把概念地图升级为可浏览的入门知识依赖网络：节点包含前置概念、来源、证据类型、适用范围、局限与练习；用户可搜索、按主题筛选、选择节点并沿前置概念导航。

## 已实现范围

- [x] 新增 `KnowledgeNetwork` 组件，并加入首页与导航。
- [x] 六个入门节点：观察与描述、解释与想法、情绪觉察、需要与价值、行动与小实验、证据与适用边界。
- [x] SVG 网络图可鼠标/键盘选择；搜索和分类筛选。
- [x] 节点详情包含前置知识、证据类型、适用范围、局限、个人练习与参考来源。
- [x] 来源链接包括 APA 的循证心理实践政策与资源页、NICE 成人抑郁症治疗指南；均提供外链，便于用户核对原文。
- [x] 明示连线只表示学习上的参考关系，不代表心理因果。
- [x] 增加移动端布局与可访问的按钮/输入标签。

## 内容治理原则

1. “证据类型”是来源性质与知识定位的描述，不是对所有心理学概念套用单一等级评分。
2. 专业组织政策、临床指南、综述、实验研究、理论模型和个人体验必须分开标注。
3. 指南中对特定临床人群的建议，不可直接外推为普通用户的自助建议。
4. 每个节点应保留适用人群、语境、局限与来源链接；没有可靠来源时明确标记“来源待补”，不能编造引用。
5. 个人反思结果不是实验室研究，单个人的前后变化不能单独证明因果。
6. 产品定位为心理学教育与反思工具，不诊断、不替代专业服务。

## 当前限制

- 当前为人工整理的六节点演示网络，不是完整心理学学科图谱。
- 节点与边写在组件内，尚未抽离为 JSON/TS 数据目录或接入数据库。
- 尚无来源更新监测、版本历史、专家审核工作流和统一证据分级体系。
- 本版未验证生产构建、真实浏览器交互或 Netlify 部署；此前依赖安装存在 DNS/网络阻塞。静态预检查不等于 TypeScript 编译成功。

## 验收步骤

1. `npm install` 并提交 `package-lock.json`。
2. `npm run check:deploy`。
3. `npm run build`。
4. 桌面和移动端验证搜索、筛选、节点点击、前置概念跳转、来源链接。
5. 检查空搜索结果、窄屏布局、键盘导航和外链打开行为。
6. 核对 APA 与 NICE 原文是否支持节点所述内容，并确认指南的临床适用范围没有被泛化。
