# V0.8.0 自我认知反思验收清单

## 功能范围

- 记录具体情境、自我评价、对他人看法的猜测、事实线索、替代解释与下一步行动。
- 情境和自我评价为必填项；其他字段可留空。
- 支持多条记录、刷新恢复、逐条删除确认与 JSON 导出。
- 使用独立 `localStorage` 键 `xinge-self-awareness-v1`，不覆盖其他模块。
- 不推断他人真实想法，不输出人格类型、分数或诊断。

## 手工验收步骤

1. 进入「自我认知」，确认空状态、引导文案和表单显示正常。
2. 不填写内容直接保存，应出现必填提示。
3. 只填写情境但不填写自我评价，仍应阻止保存。
4. 填写情境、自我评价及可选字段后保存，确认记录出现在右侧历史列表。
5. 刷新页面，确认记录仍在。
6. 导出 JSON，确认包含 `format: xinge-self-awareness` 和 `reflections` 数组。
7. 删除记录时取消确认，记录应保留；确认后记录应移除。
8. 无记录时导出按钮应禁用；有记录时可正常导出。
9. 检查窄屏布局、键盘可操作性和状态提示。
10. 确认该模块只使用自己的存储键，情绪日记、价值观罗盘和成长实验记录不受影响。
